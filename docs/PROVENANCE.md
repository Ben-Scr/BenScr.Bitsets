# Provenance

Created by Ben Schneider — https://github.com/Ben-Scr

BenScr.Bitsets is a new independent implementation. It contains no private repository code,
bundled third-party implementation or migrated legacy API. Standard-library containers and C++20
bit-counting operations provide storage and word primitives.

The CMake/NuGet verification infrastructure adapts public
[BenScr.Binary](https://github.com/Ben-Scr/BenScr.Binary/tree/28862b49402f0ca04bb4354b1fd88a738cfd7f3b)
at commit `28862b49402f0ca04bb4354b1fd88a738cfd7f3b`. Library code, tests, API contracts and examples
are specific to Bitsets. The GitHub target name was checked before creation.

The original custom `LICENSE.txt` is copied without byte changes, including CRLF line endings.
SHA-256: `f6600e285e17c48188a65745d7595807e1755c72201e8eef201a9174fca18573`.

The unchanged `branding/BenScr_Icon_Master.png` is the shared original: RGBA, 1254 x 1254,
795819 bytes, embedded as `icon.png`. SHA-256:
`a5dcabceb766e13c1840a95130ee98a458e12e3713fd9b07f3ceae75a1f5b993`.
No transformed logo or resized derivative is shipped. Gallery rendering is verified after indexing.
